Perfil

Estudiante avanzado de Ingeniería Informática en la Universidad Estatal a Distancia de Costa Rica (UNED) desde 2021, y lo combino con mi trabajo en soporte de sistemas empresariales SAP Business One, lo que me permite llevar lo que aprendo en desarrollo y bases de datos a problemas reales de negocio.

Gracias a la alianza entre Oracle y Alura Latam obtuve una beca del programa Oracle Next Education (ONE), donde me formé en desarrollo Full Stack con instructores con experiencia, y de ese programa salieron los proyectos web que verás más abajo.

En la universidad amplié esa base con C# y ASP.NET, APIs RESTful, aplicaciones de escritorio, bases de datos y redes, además de investigación de operaciones y compiladores.

Proyectos

Proyecto personal

Biblioteca personal

Aplicación web full-stack para gestionar una biblioteca personal: catálogo de más de 300 libros, usuarios, préstamos y devoluciones, con una API REST en Node.js y Express, base de datos PostgreSQL, autenticación con JWT y despliegue en Railway y GitHub Pages.

Migré la base de datos de SQL Server a PostgreSQL para poder desplegarla en la nube.

  • Node.js
  • Express
  • PostgreSQL
  • JWT
  • Railway

Proyecto universitario · Fundamentos de Programación Web, UNED · II cuatrimestre 2026

Hospedaje Guanacaste

Sistema web de gestión hotelera en tres capas (ASP.NET Core MVC, Web API RESTful y acceso a datos con Entity Framework Core sobre SQL Server 2022), que administra clientes, empleados, habitaciones y reservaciones, con validación de traslape de fechas, cálculo de descuento e IVA, integridad referencial y un reporte semanal de reservaciones.

Se desarrolló en tres etapas: MVC, API RESTful y base de datos relacional en 2FN.

  • C#
  • ASP.NET Core
  • Web API
  • Entity Framework Core
  • SQL Server

Proyecto universitario · Programación Avanzada con C#, UNED · II cuatrimestre 2026

Boletería UNED

Sistema de boletería para partidos de fútbol, hecho en C# con arquitectura en capas y programación orientada a objetos, con una primera versión de escritorio en Windows Forms y una segunda que agrega SQL Server, un servidor TCP con clientes concurrentes y control de ventas con multihilo.

Es el único de mis proyectos con sockets TCP y multihilo.

  • C#
  • Windows Forms
  • SQL Server
  • TCP
  • Multihilo
